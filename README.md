# Assimilation Technology — static website

Static HTML/CSS/JS for [assimilationtech.com](https://assimilationtech.com/). GitHub Pages publishes from `main` / `/ (root)`.

Copy is taken from the live Hostinger site and from Texas public filings. It is **not** a generic managed-IT brochure.

## What this company is

- **Name:** Assimilation Technology (legal entity: Assimilation LLC, Texas)
- **Work:** Healthcare data exchange in hospital and provider systems; integration and automation
- **Public claims on the live site:** operating since 2012; more than 18 years of experience in healthcare data exchange
- **Texas SOS:** domestic LLC filed 17 August 2014; registered agent / owner David Jarvis

HL7, FHIR, and HIE/HIN language reflects the principal’s published professional focus. Phone, email, social profiles, testimonials, and extra staff names are **not** invented.
